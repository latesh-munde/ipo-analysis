# Feature Documentation

Feature docs describe current implemented behavior, usage, contracts, configuration, and troubleshooting.

## Naming

Use a stable name such as `application-foundation.md` or `document-upload.md`.

## Template

```markdown
# Feature: Name

- Status: Proposed | In progress | Implemented | Deprecated
- Last verified: YYYY-MM-DD
- Related plan:
- Related ADRs:

## Purpose
## User workflow
## Current behavior
## Inputs and outputs
## API / UI contract
## Validation and error handling
## Dependencies and configuration
## Evidence provenance (where applicable)
## Tests and verification
## Limitations
## Troubleshooting
## Related documentation
```

Only mark a feature implemented after checking source code. Update existing docs when behavior changes rather than creating duplicates.
